# skills/

本目录承载可被 agent 运行时本地加载的技能（skill）。

## 约定

- **一技能一目录**：每个技能对应一个子目录 `skills/<skill-id>/`，目录名使用小写短横线命名（kebab-case）。
- **自包含**：该技能引用的所有内容（`SKILL.md`、脚本、资源、示例数据）必须放在同一个目录里。禁止依赖仓库其他目录中的私有资源才能运行——整个 `skills/<skill-id>/` 目录应当可以被复制到别处继续独立使用。
- **入口文件**：每个技能目录至少包含一个 `SKILL.md`，说明这个技能做什么、什么时候用、怎么调用。
- **不发布到 npm**：新增/修改一个技能，提交合并即生效，不需要打包、发版或上传到任何包管理器。

## 示例结构

```text
skills/
└── example-skill/
    ├── SKILL.md       # 必需：技能说明
    ├── scripts/       # 可选：该技能专用的脚本
    └── assets/        # 可选：该技能专用的资源/示例数据
```

## 当前状态

本目录目前只有约定说明，尚未包含任何真正实现的技能。新增技能时请遵循上述约定，并同步在 `docs/roadmap.md` 的验收矩阵中登记对应的端到端验证。

## 脱敏提醒

技能目录里的任何脚本、示例、fixture 都不得包含真实密钥、token、密码、内网地址或客户数据。示例一律使用占位符或脱敏后的假数据，详见仓库根目录 `AGENTS.md` 的脱敏硬规则。
