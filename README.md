# dsh-plugins

DSH 插件集合项目：集中登记、发现、管理各类可被 agent 运行时（例如 Mira 或其他兼容宿主）使用的插件。本仓库**不是** skills/MCP 专属实现仓库——插件可来自不同类别（技能、MCP 工具、未来其他扩展形态），统一按"一插件一目录"约定登记。本仓库不发布到 npm 或任何公共包管理器，所有插件通过仓库本身本地登记、本地加载。

Skills 管理、MCP 管理 UI 是插件集合之上规划的**管理面**能力（登记/浏览/审阅），不等同于把这些插件的完整实现搬进本仓库；真实实现来源可以是仓库内联代码，也可以是指向外部代码库的登记信息。

## 目录

- [`docs/roadmap.md`](docs/roadmap.md) — 项目画像与方向：目标状态、非目标铁律、验收矩阵。
- [`AGENTS.md`](AGENTS.md) — 开发规约：目录约定、边界、提交规范、脱敏硬规则。
- [`plugins/`](plugins/) — 插件登记集合，一插件一目录。

## 质量与验收

新增插件登记项或管理面能力时，必须同步更新 [`docs/roadmap.md`](docs/roadmap.md) 中的验收矩阵，并至少覆盖一条 Happy Path 端到端验证。任何提交、示例、文档都必须脱敏——禁止提交真实密钥、内网地址或客户数据，详见 [`AGENTS.md`](AGENTS.md)。
