# mcp/

本目录承载 MCP（Model Context Protocol）server / 工具定义的**本地登记信息**。

## 约定

- **一登记项一目录**：每个 MCP 登记项对应一个子目录 `mcp/<mcp-id>/`，目录名使用小写短横线命名（kebab-case）。
- **登记而非实现**：如果某个 MCP server 需要独立的代码实现，`mcp/<mcp-id>/` 下放的是登记/配置说明（这个 server 是什么、指向哪个代码库、暴露哪些工具），而不必是该 server 的全部源码。
- **不发布到 npm**：MCP 登记项通过本地/仓库内加载生效，不经过任何公共包管理器。
- **具体 schema 待定**：登记项的元数据格式（如需要哪些字段描述一个 MCP server）留给后续实现决定，新增时请在对应目录的 README 或说明文件里写清楚当前采用的格式，避免不同登记项各自为政。

## 示例结构

```text
mcp/
└── example-mcp/
    ├── README.md      # 必需：这个 MCP 登记项是什么、指向哪、暴露哪些工具
    └── config.example # 可选：配置示例（必须脱敏，只用占位符）
```

## 当前状态

本目录目前只有约定说明，尚未包含任何真正的 MCP 登记项。新增登记项时请遵循上述约定，并同步在 `docs/roadmap.md` 的验收矩阵中登记对应的端到端验证。

## 脱敏提醒

MCP 登记项中的任何配置示例都不得包含真实密钥、token、密码、内网地址或客户数据。示例一律使用占位符或脱敏后的假数据，详见仓库根目录 `AGENTS.md` 的脱敏硬规则。
